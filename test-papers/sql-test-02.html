10 PRACTICE QUESTIONS

01

Write a query to display DeptID, total salary, and employee count for employees whose Salary is greater than 20000 and who joined after '2020-01-01', grouped by DeptID, showing only departments where total salary exceeds 80000, sorted by total salary in descending order.

02

Write a query to display CustomerID and total order amount for orders placed between '2023-01-01' and '2023-12-31' with Amount greater than 500, grouped by CustomerID, showing only customers with more than 3 orders and total amount greater than 8000, sorted by total order amount in ascending order.

03

Write a query to display EmpName, JoiningDate, and the number of complete years of service (using DATEDIFF), and also display ManagerID replacing NULL values with 'No Manager Assigned'.

04

Write a query to display EmpName and JoiningDate for employees who joined in the last quarter of any year (October, November, December — use MONTH or QUARTER function), and display their ManagerID using COALESCE with a default value of 0.

05

Write a query to display EmpName in proper case format by showing the first letter capitalized and rest lowercase (using UPPER, LOWER, LEFT, SUBSTRING/RIGHT), along with the total length of the name.

06

Write a query to display EmpName along with their Manager's Name, by joining the Employees table with itself (EmpID = ManagerID).

07

Write a query to display OrderID, OrderDate, CustomerName, and Amount by joining Orders with Customers, showing only orders with Amount greater than 1000.

08

Write a query to display EmpName and Salary of employees whose Salary is greater than the average salary of the entire company (use a subquery in WHERE clause).

09

Write a query using a CTE to rank employees within each department based on their Salary in descending order (use RANK() or DENSE_RANK() window function with PARTITION BY), and display EmpName, DeptID, Salary, and Rank.

10

Write a stored procedure GetHighEarners that accepts DeptID and a MinSalary threshold as input parameters, declares a variable to store the count of matching employees, and returns the list of employees in that department earning more than the given threshold along with printing the total count using the declared variable.
