15 PRACTICE QUESTIONS

01

Differentiate between DELETE, TRUNCATE, and DROP with suitable examples.

02

What is the difference between the ALTER and UPDATE commands? Explain with examples.

03

What is the difference between DDL and DML commands? List at least five commands under each category.

04

What is the purpose of the INSERT statement? Explain the different ways to insert records into a table.

05

Explain the different operations that can be performed using the ALTER TABLE statement with examples.

06

Write a SQL query to create a table named Employees with the following columns:

  • EmpID
  • EmpName
  • Email
  • Mobile
  • Salary
  • ManagerID
  • DeptID
07

Write a SQL query to alter the Employees table by adding the following columns:

  • JoiningDate
  • Bonus
  • Designation
08

Write a SQL query to rename the following columns in the Employees table:

  • Mobile → PhoneNumber
  • Salary → BasicPay
09

Write a SQL query to remove the following columns from the Employees table:

  • Bonus
  • Designation
10

Write a SQL query to insert 10 employee records into the Employees table.

11

Write a SQL query to insert 5 employee records using a single INSERT statement.

12

Write a SQL query to increase the BasicPay of all employees by 15%.

13

Write a SQL query to update the DeptID to 5 and the ManagerID to 101 for all employees.

14

Write a SQL query to delete all employees whose BasicPay is less than 30,000.

15

Write SQL queries to:

  • Truncate all records from the Employees table.
  • Drop the Employees table.
