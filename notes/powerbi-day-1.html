POWER BI · DAY 1

Introduction to Power BI

My first Power BI learning notes — understanding Power BI, data sources, Power Query, data modeling, DAX, visualizations and reports.

🧠 What I Understood

Power BI is a Microsoft business analytics and data visualization tool. It can take data from different sources, help clean and transform the data, organize it into a model, perform calculations and present the results through interactive reports and visualizations.


The main purpose is to make business data easier to understand so that people can identify things such as sales performance, changes in sales and other important business insights.

📚 Important Terms I Learned

Data Source

The place from which data comes, such as Excel, SQL databases, CSV files or web data.

Table

Data arranged in rows and columns.

Row

One record in a table.

Column

One type of information in a table.

Power Query

Used to connect, clean, transform and reshape data before loading it.

Data Model

An organized structure of tables and their relationships.

DAX

Data Analysis Expressions, used for calculations in Power BI.

Visualization

A visual representation of data, such as charts, tables and maps.

Report

A report can contain one or more pages of visuals used to analyze data.

Dashboard

A high-level, single-page view containing tiles and visuals.

🔗 Data Modeling

Data modeling helps connect related tables instead of keeping all information inside one huge table.


Example: Customers → Sales ← Products

🧮 DAX

DAX stands for Data Analysis Expressions. It is used to create calculations in Power BI.


Example:


Total Sales = SUM(Sales[Amount])

One important point I learned: DAX is not SQL.

📸 My Original Handwritten Notes

⭐ My Key Takeaway

Power BI is not just about creating charts. The process starts with data and goes through cleaning, modeling, calculations and visualization so that the final information can help people understand the business.
