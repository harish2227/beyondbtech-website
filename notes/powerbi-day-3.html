POWER BI · DAY 3

Basic Data Cleaning in Power Query

Data Power BI lo load chesina taruvatha direct ga visuals create cheyyadam kanna, first data ni understand chesi, correct format lo undho check cheyyali. Ee work lo Power Query Editor chala important role play chestundi.

💡 Beginner Tip: Power Query data load ayinappudu column data types ni automatic ga detect chestundi. Kani automatic detection ni blindly trust cheyyakunda, manam data type correct ga undho once verify cheyyali. Wrong ga unte correct type ki change cheyyali.

🧹 Why do we clean data first?

Real projects lo data always perfect ga undadu. Different sources nunchi vachina data lo wrong data types, unwanted columns, duplicate records, errors or inconsistent values undachu. Analysis correct ga ravali ante data ni first prepare cheyyali.

Raw Data → Check → Clean & Transform → Data Model → Visuals → Business Insights

1️⃣ Power Query automatically detects data types

DATA TYPES

Automatic detection happens when data is loaded

Manam Excel, CSV, Folder or other source nunchi data load chesinappudu, Power Query columns ni observe chesi appropriate data type ni automatically assign cheyyadaniki try chestundi.

Example ga, dates ni Date ga, numbers ni Whole Number / Decimal Number ga, names or IDs ni Text ga detect cheyyachu.

5 → Whole Number
125.50 → Decimal Number
28-08-2024 → Date
CA-2019-121188 → Text
Standard Class → Text
TRUE / FALSE → True/False

2️⃣ Always verify the detected data type

IMPORTANT PRACTICE

Automatic detection correct ayina, verify cheyyadam important

Power Query automatic ga type detect chesina taruvatha, manam column values ni observe chesi type actual meaning ki match avutundho check cheyyali.

For example, Order Date ane column Date ga undali. Adi Text ga detect ayithe, calculations, filtering and date-based analysis lo problems ravachu.

Simple rule:
Column lo unna value ni chusi → aa value meaning enti ani understand chesi → correct data type assign cheyyali.

3️⃣ Change Type

RIGHT CLICK → CHANGE TYPE

Wrong data type unte correct type ki change cheyyachu

Column meeda right-click chesi Change Type option ki vellithe, different data types select cheskovachu.

Example: oka Date column Text ga detect ayithe, Text → Date ga convert cheyyachu. Same way numbers ki Whole Number or Decimal Number select cheyyachu.

⚠️ Remember: Data already correct ga unte just practice kosam type ni change cheyyalsina avasaram ledu. Real project lo requirement and actual data meaning batti type ni change chestam.

4️⃣ Applied Steps — what happened to our data?

POWER QUERY EDITOR

Every transformation is recorded

Power Query lo manam data meeda oka transformation apply chesthe, adi right side unna Applied Steps section lo record avutundi.

Example ga source load cheyyadam, headers promote cheyyadam, data type change cheyyadam ila manam chesina transformations steps ga visible untayi.

Why is this useful?
Manam data ni ela transform chesamo easy ga track cheyyachu. Previous step ki vellachu, step ni modify cheyyachu or unnecessary step ni remove cheyyachu.

5️⃣ Remove unwanted columns — based on business requirements

REAL-WORLD PRACTICE

Why are we removing columns?

Beginners ki common doubt: “Table lo column undi kada, enduku remove cheyyali?”

Real projects lo every column ni compulsory ga analysis lo use cheyyamu. Business ki kavalsina questions and requirements batti required columns ni identify chestam. Analysis ki avasaram leni columns ni remove cheyyachu.

Example:
Business question: “Category and Product wise Sales entha?”

Ee question ki useful columns: Category, Product, Sales.
Ee analysis ki use leni extra column ni remove cheyyachu.

Remove Columns = random ga data delete cheyyadam kaadu. It should be based on the analysis requirement and business requirement.

6️⃣ Useful right-click options

QUICK REFERENCE

Column meeda right-click chesthe useful options

Change Type

Column data type ni correct type ki change chestundi.

Remove

Selected column ni table nunchi remove chestundi.

Remove Other Columns

Selected column(s) ni keep chesi, migatha columns ni remove chestundi.

Remove Duplicates

Selected column(s) basis meeda duplicate rows ni remove cheyyadaniki use chestam.

Remove Errors

Selected column lo error values unna rows ni remove cheyyadaniki use cheyyachu.

Replace Values

Oka value ni another value tho replace cheyyadaniki use chestam.

Rename

Column name ni meaningful and clear name ga change cheyyadaniki use chestam.

Power BI lo data load chesina taruvatha, immediate ga visuals create cheyyakunda first data ni understand cheyyali.

Automatic data type detection → Verify → Correct if required → Transform based on requirements → Track everything in Applied Steps
