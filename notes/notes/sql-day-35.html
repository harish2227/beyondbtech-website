CTE — Common Table Expression

A simple explanation of CTEs and why they are useful when writing complex SQL queries.

What is a CTE?

CTE stands for Common Table Expression. It allows us to temporarily store the result of a query and use that result in another query.

Basic Syntax

WITH CTE_Name AS ( SELECT column1, column2 FROM Employee ) SELECT * FROM CTE_Name;

Example

Suppose we want to find employees whose salary is greater than the average salary.

WITH AvgSalary AS ( SELECT AVG(emp_sal) AS avg_sal FROM Employee ) SELECT e.emp_name, e.emp_sal FROM Employee e CROSS JOIN AvgSalary a WHERE e.emp_sal > a.avg_sal;

Why use a CTE?

CTEs make complex queries easier to read, understand and maintain.

💡 Interview Tip: CTEs are commonly used when a query needs multiple logical steps or when the result needs to be referenced more clearly.

Remember

Think of a CTE as a temporary named result that exists only while the query is running.
