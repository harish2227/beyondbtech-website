Custom Column

Create a new column using your own formula or rule.

CONCEPT

What does Custom Column mean?

Custom Column is used when we want to create a new column by writing our own formula or rule using existing columns.

Bro, Custom Column ante maname oka formula or rule create chesi, already unna columns ni use cheskoni kotha column create cheyyadam.

💼 Simple Example

Sales | Quantity 2000 | 4 600 | 3 900 | 5

Business requirement: each order ki sales per quantity calculate cheyyali.

New Column: Sales Per Quantity Formula: [Sales] / [Quantity] 2000 / 4 = 500 600 / 3 = 200 900 / 5 = 180
HOW IT WORKS
Existing Columns
→
Write Formula
→
New Column
MORE THAN NUMBERS

Custom Column is not only for mathematical calculations. Text and date functions can also be used.

Examples

[First Name] & " " & [Last Name] Text.Upper([Product Name]) Date.Year([Order Date]) if [Sales] >= 1000 then "High" else "Low"

02

Conditional Column

Create a new column based on conditions.

CONCEPT

What does Conditional Column mean?

Conditional Column checks values in an existing column and creates a new result based on conditions. It is similar to IF / ELSE IF / ELSE thinking.

Bro, oka column lo unna value ni check chesi, “idi ila unte ee result ivvu, adi ala unte vere result ivvu” ani conditions set chesi new column create chestam.

💼 Sales Example

Sales >= 1000 → High Sales >= 500 → Medium Otherwise → Low
1500 → High 800 → Medium 300 → Low 1200 → High
IMPORTANT — ORDER MATTERS

Power Query checks multiple conditions from top to bottom. The first matching condition gives the result.

⚠️ Why?

Correct order: Sales >= 1000 → High Sales >= 500 → Medium Otherwise → Low If >= 500 is placed first, 1200 would match it and become Medium.
CUSTOM COLUMN vs CONDITIONAL COLUMN

Column From Examples

Give examples and let Power Query infer a pattern.

CONCEPT

How does Column From Examples work?

We provide a few expected outputs for existing values. Power Query tries to identify the pattern and suggests results for the remaining rows.

Bro, exact formula rayakunda, “input ila unte output ila kavali” ani konni examples istam. Power Query aa examples lo pattern ni identify cheyyadaniki try chesi remaining rows ki result suggest chestundi.

💼 Easy Example

Name → First Character Harish → H Ravi → R Kiran → K

Here the pattern is simple: each output is the first character of the Name.

HOW IT WORKS
Select Column
→
Column From Examples
→
Give Examples
→
Check Suggested Results

⚠️ Important

Column From Examples is pattern inference, not magic. Always verify the suggested results, especially when the pattern can be interpreted in more than one way. If the rule is already exact and clear, an explicit transformation or formula may be better.

Index Column

Add sequential numbers to rows.

CONCEPT

What is an Index Column?

An Index Column gives rows sequential numbers and creates a new column.

Bro, mana table lo unna prathi row ki sequence number ivvali anukunte Index Column use chestam.

💼 Example

Index | Customer | Sales 1 | Ravi | 500 2 | Kiran | 800 3 | Suresh | 300 4 | Harish | 1000
THREE COMMON OPTIONS

From 0

0, 1, 2, 3, ...

From 1

1, 2, 3, 4, ...

Custom

Example: Start = 100 Increment = 10 100, 110, 120, 130, ...
WHY USE IT?

Index can help with row identification, tracking sequence during transformations, and acting as a helper column for later logic.

Index number is usually a helper/sequence value. It should not automatically be confused with a real business ID such as Customer ID or Order ID.

Duplicate Column

Copy an existing column before transforming the copy.

CONCEPT

Why do we duplicate a column?

Duplicate Column creates an exact copy of an existing column. The main idea is to preserve the original while we transform the copy.

Bro, original column ni safe ga unchukoni, dani oka copy create cheskoni, aa copy meeda transformations cheyyadaniki Duplicate Column use chestam.

💼 Example — 10% Increase

Original Sales 1000 500 800 After Duplicate: Sales | Sales - Copy 1000 | 1000 500 | 500 800 | 800

Now transform the copy: Multiply by 1.10

Sales | Sales - Copy 1000 | 1100 500 | 550 800 | 880
TRANSFORMATION MEANING

Transformation ante existing data ni required format or result ki change cheyyadam.

Original
→
Duplicate
→
Transform Copy
→
Keep Original + New Version

💡 Remember

Duplicate Column itself does not transform the value. First it creates a copy; then you can apply transformations to that copy.

Text / Number / Date

Transform different data types according to the requirement.

TEXT

Text transformations

Text columns nunchi required portions extract cheyyadaniki or values ni split/format cheyyadaniki text transformations use chestam.

Example: CA-2019-121188-120

First Characters (3) → CA- Last Characters (3) → 120 Before first "-" → CA After first "-" → 2019-121188-120 Between delimiters → 2019 / 121188

Full Name → First Name + Last Name

Harish Gundekari ↓ Split Column → By Delimiter → Space Harish | Gundekari
NUMBER

Number transformations

Number values meeda calculations or adjustments apply cheyyachu.

Example

Sales = 1000 Multiply by 1.10 1000 → 1100
DATE

Extract useful information from dates

Date column nunchi Year, Quarter, Month Name and Month Number lanti information create cheyyachu.

Example: Order Date = 15-08-2026

Date → Year → 2026 Date → Quarter → 3 Date → Month → Name of Month → August Date → Month → Month → 8

Quarter Number → Q1 / Q2 / Q3 / Q4

1 → Q1 2 → Q2 3 → Q3 4 → Q4 Custom Column example: if [Quarter] = 1 then "Q1" else if [Quarter] = 2 then "Q2" else if [Quarter] = 3 then "Q3" else "Q4"
WHY DATA TYPE MATTERS

First data type understand cheyyali, then appropriate transformation select cheyyali.

Text → Text Operations
Number → Numerical Operations
Date → Date Operations

💡 Remember

Requirement → Required information → Correct transformation. Month Name is useful for display, while Month Number can help with chronological sorting.

Invoke Custom Function

A simple introduction to reusable logic.

CONCEPT

What is a Custom Function?

A Custom Function lets us create reusable logic once and use that same logic on different data when needed.

Bro, manam oka logic ni function laga create cheskunte, same logic ni malli malli manually rayakunda different data meeda reuse cheyyachu.

💼 Simple idea

Create reusable logic: Sales + 10% Then apply it: 1000 → 1100 500 → 550 800 → 880
WHAT DOES "INVOKE" MEAN?

Invoke ante simple ga call/use cheyyadam. Function already create chesina tarvatha, aa function ni required data meeda apply cheyyadam is invoking the custom function.
