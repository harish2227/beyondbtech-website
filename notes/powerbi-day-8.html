Add Column in Power Query

Day 8 lo manam Power Query lo Add Column option ni practical ga nerchukunnam. Existing data ni use chesi new columns ela create cheyyalo different methods tho practice chesam.

💡 Main idea
Add Column ante existing data ni base cheskoni new information / calculation / classification create cheyyadam. Requirement batti correct method select cheyyali.
1

Custom Column

Custom Column ante maname formula or rule create chesi, existing columns ni use chesi new column create cheyyadam.

Telish: Manaki exact formula telusu ante, maname formula rayachu. Example ga Price and Quantity unte Sales calculate cheyyachu.
[Price] * [Quantity]

Text columns tho kuda Custom Column work avtundi. Example:

[First Name] & " " & [Last Name]

Text, numbers and dates kosam appropriate Power Query functions ni use cheyyachu.

2

Conditional Column

Conditions or rules based ga new column create cheyyadaniki Conditional Column use chestham.

Sales >= 1000 → High Sales >= 500 → Medium Otherwise → Low
Telish: Idi basically IF / ELSE IF / ELSE thinking laga. Business requirement batti values ni categories ga divide cheyyachu.
Important: Multiple conditions unte order matters. Power Query conditions ni top-to-bottom check chestundi. Kabatti higher threshold ni first pettadam important.

3

Column From Examples

Column From Examples lo manam konni input → expected output examples isthe, Power Query aa examples nundi pattern ni infer chesi remaining rows ki apply cheyyadaniki try chestundi.

Telish: Formula rayakunda examples ichi, “nenu ila output kavali” ani Power Query ki chupistam. Power Query pattern ni understand cheyyadaniki try chestundi.
InputExample Output
Los AngelesLos
San FranciscoSan
Costa MesaCosta
Important: Idi magic kaadu. Pattern clear ga unte result better ga infer cheyyagaladu. Generated result ni always verify cheyyali.

4

Index Column

Rows ki sequential numbers assign cheyyadaniki Index Column use chestham.

1 2 3 4 5 ...

Manam practice lo Add Column → Index Column → From 1 use chesam. Starting value and increment ni requirement batti customize cheyyachu.

📸 Your Index Column screenshotIkkada mana actual screenshot add cheyyali.
5

Duplicate Column

Existing column ni exact copy ga create cheyyadaniki Duplicate Column use chestham.

Why? Original column ni unchanged ga preserve chesthu, copy meeda transformation cheyyachu.

Example: Sales column ni duplicate chesi copy meeda 10% increase cheyyachu.

Sales Copy × 1.10

Power Query lo copy select chesi Transform → Standard → Multiply → 1.10 use cheyyachu.

6

Text, Number & Date Based Columns

Existing column type batti Add Column lo useful information ni derive cheyyachu.

Text examples

  • First Characters: City → first 3 characters
  • Last Characters: City → last 3 characters
  • Text Before Delimiter: delimiter mundu unna text
  • Text After Delimiter: delimiter tarvatha unna text
  • Split Column: Full Name → First Name + Last Name
CA-2019-121188-120 Before first - → CA After first - → 2019-121188-120 Between first and second - → 2019

Date examples

Order Date nundi manam practical ga:

  • Year → 2026
  • Quarter → 1, 2, 3, 4
  • Quarter label → Q1, Q2, Q3, Q4
  • Month Name → January, February...
  • Month Number → 1–12
Business reporting tip: Month Name display kosam useful. Month Number chronological sorting kosam useful.

7

Invoke Custom Function

Same logic ni multiple tables or data sources ki repeatedly apply cheyyali anukunte reusable custom function create chesi invoke cheyyachu.

CalculateSales(Price, Quantity) → reusable logic → different data can use the same function
Day 8 status: Ee concept ni ippudu introductory level lo understand chesam. Detailed custom function creation and parameters ni later practical ga nerchukundam.

🎯 Day 8 Takeaway

Add Column ante just new column create cheyyadam kaadu. Business requirement ni understand chesi, correct transformation method select cheyyadam important.

Formula teliste → Custom Column
Condition unte → Conditional Column
Pattern examples tho cheppali ante → Column From Examples
Row numbering kavali ante → Index Column
Copy meeda work cheyyali ante → Duplicate Column
Text/Date information derive cheyyali ante → Extract / Date options
