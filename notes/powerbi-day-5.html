POWER BI · DAY 5

Filtering and Sorting Data in Power Query

Data cleaning tarvata, manaki required data ni select cheyyadam and data ni proper order lo arrange cheyyadam important. Ee roju Power Query lo Filtering and Sorting concepts ni beginner-friendly examples tho nerchukundam.

🧠 Today manam em nerchukuntam?

Power Query lo data ni transform chestunnappudu, manaki anni rows always avasaram undavu. Business requirement batti required rows ni select cheyyalsi untundi.

Alage, data ni smallest to largest or highest to lowest order lo arrange cheyyalsina situations untayi.

Ee rendu concepts ni ee lesson lo nerchukuntam:

  • Filtering — Required rows ni select cheyyadam.
  • Sorting — Data ni specific order lo arrange cheyyadam.
STEP 1

What is Filtering?

Imagine mana company daggara thousands of sales records unnayi.

Kani manager manalni ila aduguthe:

"Show me only Technology category sales."

Appudu manaki anni records avasaram undavu. Technology category ki related records matrame kavali.

Required condition ni satisfy chese rows ni select cheyyadam ni Filtering antam.

Business Requirement ↓
Choose Required Data ↓
Apply Filter ↓
Analyze Results
STEP 2

Why Do We Filter Data?

Real projects lo business ki different questions untayi. Prathi question ki complete dataset avasaram undakapovachu.

For example:

Category Product Sales
Furniture Chair 500
Technology Laptop 1000
Office Supplies Paper 200
Technology Monitor 700

Business asks:

"Show only Technology products."

Appudu Furniture and Office Supplies rows current analysis ki avasaram undavu. Technology rows matrame select cheyyachu.

Business Question ↓ Required Data ↓ Apply Appropriate Filter ↓ Analyze Results
STEP 3

How to Filter Data in Power Query

Filtering apply cheyyadaniki mundu, manam which column base cheskoni filter cheyyalo identify cheyyali.

Mana example lo:

Business Requirement: Show only Technology category products.

Kabatti manam Category column ni use chestam.

Follow These Steps

1. Find the Column
Filter apply cheyyali anukunna column ni identify cheyyandi.
2. Click the Dropdown
Column header daggara unna dropdown/filter button click cheyyandi.
3. Select Required Value
Available values lo required value ni select cheyyandi.
4. Click OK
Power Query selected condition ki match ayye rows ni chupistundi.
Category Column ↓ Click Filter Dropdown ↓ Select Technology ↓ Click OK ↓ Only Technology Rows

Important: Filter apply chesina tarvata Applied Steps lo usually oka new transformation step record avutundi.

STEP 4

Text Filters

Sometimes column lo thousands of different text values undachu. Prathi value manually select cheyyadam convenient kakapovachu. Appudu Text Filters use cheyyachu.

Example: Contains

Suppose Product Name column lo ee values unnayi:

Product Name
Office Chair
Laptop
Gaming Chair
Monitor
Chair Mat

Business asks:

"Show all products containing the word Chair."
Product Name ↓ Text Filters ↓ Contains ↓ Chair

Result lo Office Chair, Gaming Chair and Chair Mat lanti matching values vastayi.

Other Useful Text Filters

Equals — Exact value match kosam.
Contains — Specific text contain chese values kosam.
Begins With — Specific text tho start ayye values kosam.

Beginner Tip: Mundu business requirement ni understand cheyyandi. Tarvata correct filter condition select cheyyandi.

STEP 5

Number Filters

Text data ni filter cheyyadaniki Text Filters use chestam. Numeric columns ni conditions base cheskoni filter cheyyadaniki Number Filters use chestam.

Example:

Product Sales
Chair 500
Laptop 1500
Monitor 800
Table 2000
Keyboard 300
Business asks: "Show products where Sales is greater than 1000."
Sales Column ↓ Number Filters ↓ Greater Than ↓ 1000

Only Sales value 1000 kanna greater unna rows result lo untayi.

Useful Number Filters

Greater Than — Example: Sales > 1000
Less Than — Example: Quantity < 10
Between — Example: Sales between 500 and 1500
STEP 6

Date Filters

Real-world datasets lo date columns chala common. For example:

  • Order Date
  • Ship Date
  • Joining Date
  • Transaction Date

Suppose business asks:

"Show only orders placed after January 1, 2023."

Appudu Order Date column ni filter cheyyachu.

Order Date ↓ Date Filters ↓ After ↓ 01-Jan-2023

Useful Date Conditions

Before — Selected date mundu unna records.
After — Selected date tarvata unna records.
Equals — Specific date ki match ayye records.
Between — Two dates madhyalo unna records.
Important: Date Filter use cheyyadaniki mundu, aa column correct Date data type lo undho verify cheyyandi.
STEP 7

Filtering vs Sorting

Beginners ki Filtering and Sorting similar ga anipinchachu. Kani rendu different operations.

Filtering
Required condition ni satisfy chese rows ni select cheyyadam.
Sorting
Data ni specific order lo arrange cheyyadam.

Simple Example

FILTERING ↓ Which rows do I need?

SORTING ↓ In what order should I see the rows?

If You Know SQL

Filtering ≈ WHERE
SQL lo WHERE condition base cheskoni rows ni select chestundi.
Sorting ≈ ORDER BY
SQL lo ORDER BY rows ni specific order lo arrange chestundi.
STEP 8

How to Sort Data in Power Query

Sorting means data ni required order lo arrange cheyyadam.

Suppose Sales values:

500 1500 200 1000

Sort Ascending

Smallest → Largest

200 500 1000 1500

Sort Descending

Largest → Smallest

1500 1000 500 200
Business Example: Manager asks: "Show products from highest sales to lowest sales."

Solution: Sales → Sort Descending

Just like filtering, sorting apply chesina tarvata Applied Steps lo transformation record avutundi.

🎯 Try It Yourself

Practice 1
Category column ni filter chesi one category data matrame select cheyyandi.
Practice 2
Sales column lo Number Filter use chesi specific value kanna greater unna records select cheyyandi.
Practice 3
Sales column ni Descending order lo sort cheyyandi.
Practice 4
Applied Steps section lo new steps observe cheyyandi.

💡 Today's Takeaway

  • Filtering means selecting rows based on a condition.
  • Sorting means arranging data in a specific order.
  • Text data ki Text Filters use cheyyachu.
  • Number data ki Number Filters use cheyyachu.
  • Date data ki Date Filters use cheyyachu.
  • Filtering is similar to SQL WHERE.
  • Sorting is similar to SQL ORDER BY.
  • Filtering and Sorting transformations Applied Steps lo record avutayi.
Most Important Mindset:

Don't start with: "What button should I click?"

Start with: "What does the business want to see?"
