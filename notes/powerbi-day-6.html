01

Remove Top Rows

Remove unnecessary information before the actual dataset begins.

CONCEPT

What does Remove Top Rows mean?

Bro, konni datasets lo actual data start avvadaniki mundhu report title, company information, generated date or unnecessary details untayi. Avi mana actual dataset lo part kaavu. Kabatti manam Remove Top Rows option use chesi actual data mundhu unna unnecessary rows ni remove chestham.

💼 Example

Suppose we receive a sales report like this:

ABC Company Sales Report Generated on: September 2026 Confidential Order ID | Customer | Product | Sales OD101 | Ravi | Laptop | 50000 OD102 | Kumar | Mouse | 1000

Here the first three rows are not actual data. Our dataset actually starts from the Order ID row.

→

PRACTICAL DEMONSTRATION

💡 Important

Remove Top Rows works based on position. Always check where your actual dataset starts before removing rows.

02

Use First Row as Headers

Convert the first row of data into actual column names.

CONCEPT

Why do we use First Row as Headers?

Konni datasets Power Query lo load ayinappudu actual column names first row lo data laga kanipisthayi. For example, Column1, Column2 ani headers untayi and actual Order ID, Customer Name, Sales values first row lo untayi. Appudu Use First Row as Headers use chesi aa first row ni actual column headers ga convert chestham.

💼 Before

Column1 | Column2 | Column3 Order ID | Customer Name | Sales OD101 | Ravi | 5000 OD102 | Kumar | 8000

💼 After

Order ID | Customer Name | Sales OD101 | Ravi | 5000 OD102 | Kumar | 8000
HOW IT WORKS
First Row Contains Names
→
Use First Row as Headers
→
Proper Column Headers

🎥 Watch It In Action

PRACTICAL DEMONSTRATION

💡 Important

Before using this option, make sure the first row actually contains column names and not normal data.

03

Remove Blank Rows

Remove completely empty records from the dataset.

CONCEPT

What is a Blank Row?

Dataset lo konni rows completely empty ga untayi. Aa row lo Order ID, Customer, Sales or any other information emi undadu. Ila completely empty ga unna records mana analysis ki use avvavu. Kabatti Remove Blank Rows use chesi vatini remove chestham.

💼 Example

Order ID | Customer | Sales OD101 | Ravi | 500 (blank row) OD102 | Kumar | 800

The blank row is not an actual order record, so we can remove it.

HOW IT WORKS
Dataset
→
Blank Row Found
→
Remove Blank Rows
→
Clean Dataset

🎥 Watch It In Action

PRACTICAL DEMONSTRATION

💡 Important

A row with one missing value is not necessarily a blank row. Here we are talking about completely empty rows.

04

Remove Columns

Remove columns that are not needed for your analysis.

CONCEPT

Why do we remove columns?

Bro, dataset lo unna every column mana current analysis ki avasaram undakapovachu. Example ki manam Sales and Profit analysis chesthunnam anukundham. Appudu Postal Code or Row ID avasaram lekapothe aa columns ni remove cheyyachu. Ila cheste dataset clean ga and easy to understand ga untundi.

💼 Example

Our analysis requires:

Customer Name Product Sales Profit

But the dataset also contains:

Row ID Postal Code

If these columns are not required for our current analysis, we can remove them.

HOW IT WORKS
Large Dataset
→
Find Unnecessary Column
→
Remove Column
→
Cleaner Dataset

🎥 Watch It In Action

PRACTICAL DEMONSTRATION

💡 Important

A column may be unnecessary for one analysis but useful for another. Always remove columns based on your business requirement.

05

Remove Duplicates

Remove repeated records after understanding your data.

CONCEPT

What are Duplicate Records?

Dataset lo same record repeated ga unte mana analysis incorrect results ivvachu. Kani important thing enti ante same value repeated avvadam always duplicate ani kaadhu. Manam first data ni understand chesi which column should be unique ani identify cheyyali.

💼 Example

Suppose Order ID should be unique:

Order ID OD101 OD102 OD101 ← Repeated OD103

Here OD101 appears twice. If it represents the same record, we may remove the duplicate.

HOW IT WORKS
Check Data
→

→

🎥 Watch It In Action

PRACTICAL DEMONSTRATION

💡 Important

Repeated values do not always mean duplicate records. Always understand your data before removing duplicates.
