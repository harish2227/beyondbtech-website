POWER BI • DAY 7

Replace Values & Error Handling

Learn how to standardize inconsistent data and handle errors in Power Query using Replace Values, Remove Errors, Keep Errors and Replace Errors.

TOPIC 01

Replace Values

Replace Values is used to change an existing value in a column into another value. This is especially useful when the same information is stored in different formats.

💬 Easy Explanation

Bro, Replace Values ane option manaku data lo unna oka specific value ni inkoka value tho change cheyadaniki use avtundhi. Mainly same information different formats lo unnappudu data ni standardize cheyadaniki use chestam.

💡 Example
HYD → Hyderabad WGL → Warangal Second Class → Second
Important: Replace Values only changes the specified value. It does not remove the row or column.

TOPIC 02

Remove Errors

Remove Errors removes every row that contains an error in the selected column.

💬 Easy Explanation

Bro, Remove Errors use chesthe kevalam error value matrame remove avvadhu. Error unna complete row or record motham data nunchi remove aipothundhi.

💡 Example
Before: Ram | 50000 | HR Ravi | Error | IT Kiran | 60000 | Finance After Remove Errors: Ram | 50000 | HR Kiran | 60000 | Finance
Be Careful: Removing errors can also remove important information from the dataset because the complete row is deleted.
🎥 Watch & Practice — Remove Errors
TOPIC 03

Keep Errors

Keep Errors keeps only the rows containing errors and removes the normal rows from the current query result. This makes it easier to identify and investigate problematic records.

💬 Easy Explanation

Bro, Keep Errors use chesthe error unna rows matrame mana data lo kanipistayi. Normal rows anni remove aipothayi. Dheenivalla errors ekkada unnayo easy ga identify chesi investigate cheyachu.

💡 Example
Before: Ram | 50000 Ravi | Error Kiran | 60000 Suresh | Error After Keep Errors: Ravi | Error Suresh | Error
Real Job Tip: When working with thousands of rows, Keep Errors helps you quickly isolate only the problematic records before deciding how to fix them.
TOPIC 04

Replace Errors

Replace Errors is used to replace an error with another appropriate value while keeping the complete row in the dataset.

💬 Easy Explanation

Bro, Replace Errors ane option manaku data lo unna Error values ni vere appropriate value tho replace cheyadaniki use avtundhi. Error unna row matram data lo alane untundhi.

💡 Example
Before: Sales 500 Error 800 Replace Error with 0 After: 500 0 800
Important: Do not always replace an error with 0. The correct replacement depends on the column, data type and business requirement.

DATA ANALYST THINKING

What Should You Do When You Find an Error?

Finding an error does not mean that you should immediately remove or replace it. First understand why the error occurred.

ERROR ↓ Investigate Why ↓ Understand the Problem ↓ Choose the Correct Action Replace? Remove? Fix Source Data?

💬 Easy Explanation

Bro, error vachindhi ani ventane remove or replace cheyakudadhu. Mundhu aa error enduku vachindho investigate cheyali. Tarvatha data importance and business requirement batti correct action decide cheyali.

DAY 7 RECAP

Quick Summary

Option What Happens? Main Purpose

Remove Errors Complete error row is removed Remove invalid records
Keep Errors Only error rows remain Investigate errors
Replace Errors Error is replaced with another value Keep the record
