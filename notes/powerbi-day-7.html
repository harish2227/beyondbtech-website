01

Replace Values

Change a specific value into another value to keep your data consistent.

CONCEPT

What does Replace Values mean?

Replace Values is used to change an existing value in a column into another value. It is especially useful when the same information is entered in different formats.

Bro, Replace Values ane option manaku data lo unna oka specific value ni inkoka value tho change cheyadaniki use avtundhi. Mainly same information different formats lo unnappudu data ni standardize cheyadaniki use chestam.

💼 Example

HYD → Hyderabad WGL → Warangal Second Class → Second

Here the same information may be entered differently. Replace Values helps us convert it into one consistent format.

HOW IT WORKS
Different Values
→
Replace Values
→
Standardized Data

🎥 Watch It In Action

PRACTICAL DEMONSTRATION

💡 Important

Replace Values only changes the specified value. It does not remove the row or column.

02

Remove Errors

Remove records that contain errors in the selected column.

CONCEPT

What happens when we Remove Errors?

Remove Errors removes rows containing an error in the selected column.

Bro, Remove Errors use chesthe kevalam error value matrame remove avvadhu. Error unna complete row or record motham data nunchi remove aipothundhi.

💼 Example

Before: Ram | 50000 | HR Ravi | Error | IT Kiran | 60000 | Finance After Remove Errors: Ram | 50000 | HR Kiran | 60000 | Finance
HOW IT WORKS
Error Found
→
Remove Errors
→
Complete Row Removed

🎥 Watch It In Action

PRACTICAL DEMONSTRATION

⚠️ Be Careful

An error may exist in only one column, but Remove Errors can remove the complete row. Always check whether that record contains important information.

03

Keep Errors

Keep only the error records so you can investigate them.

CONCEPT

Why do we use Keep Errors?

Keep Errors keeps only the rows containing errors and removes normal rows from the current query result. This makes it easier to identify problematic records.

Bro, Keep Errors use chesthe error unna rows matrame mana data lo kanipistayi. Normal rows anni remove aipothayi. Dheenivalla errors ekkada unnayo easy ga identify chesi investigate cheyachu.

💼 Example

Before: Ram | 50000 Ravi | Error Kiran | 60000 Suresh | Error After Keep Errors: Ravi | Error Suresh | Error
HOW IT WORKS
Large Dataset
→
Keep Errors
→
Only Error Rows

💡 Real Job Tip

Instead of immediately removing an error, use Keep Errors to first identify which records are problematic and understand why the error occurred.

04

Replace Errors

Replace an error with an appropriate value while keeping the complete row.

CONCEPT

What does Replace Errors do?

Replace Errors is used to replace an error with another appropriate value while keeping the complete record in the dataset.

Bro, Replace Errors ane option manaku data lo unna Error values ni vere appropriate value tho replace cheyadaniki use avtundhi. Error unna row matram data lo alane untundhi.

💼 Example

Before: 500 Error 800 Replace Error with 0 After: 500 0 800
HOW IT WORKS
Error Found
→
Replace Errors
→
Appropriate Value
→
Row Remains

🎥 Watch It In Action

PRACTICAL DEMONSTRATION

💡 Important

Do not always replace an error with 0. The correct replacement depends on the column, data type and business requirement.

DATA ANALYST THINKING

What Should You Do When You Find an Error?

Don't immediately remove or replace an error. First understand why the error occurred and then choose the correct action.

Error Found
→
Keep Errors
→
Investigate Why
→
Understand Problem
→
Replace / Remove / Fix

🧠 Remember

Bro, error vachindhi ani ventane remove or replace cheyakudadhu. Mundhu aa error enduku vachindho investigate cheyali. Tarvatha data importance and business requirement batti correct action decide cheyali.
