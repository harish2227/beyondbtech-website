02 / Power BI

02
FundamentalsBeginner
What is Power BI?

“Power BI is a Microsoft business intelligence and data visualisation tool. It helps us connect to data, prepare and model it, create calculations, and build interactive reports so people can understand business performance and make decisions.”

03
ViewsBeginner
What are the different views in Power BI Desktop?

“The main views in Power BI Desktop are Report view, Table view and Model view. Report view is where we build report pages and visuals. Table view lets us inspect data loaded into the model and work with model columns. Model view shows tables and their relationships. Some versions also provide DAX query view for writing and running DAX queries. Power Query Editor is where we clean and transform data; it is a separate editor, not one of the three classic views.”

04
DAXIntermediate
What is the difference between a calculated column and a measure?

“A calculated column creates a value for each row and stores those values in the model. A measure calculates a single result when a visual needs it, based on the current filter context. I use a calculated column for row-level values or categories, and a measure for totals, averages, percentages and other report calculations. Calculated columns can increase model size, while measures do not store a result for every row.”

05
DAX ContextIntermediate
What are row context and filter context?

“Row context means DAX is evaluating an expression for a particular row. It occurs in calculated columns and in iterator functions such as SUMX. Filter context is the set of filters that decides which data a calculation can use. It can come from slicers, visual fields, page filters, report filters or DAX.”

For example, selecting South in a Region slicer filters a Total Sales measure to South, assuming the model relationships and visual interactions allow that filter to reach the sales data. Row context and filter context are different concepts, although some DAX functions can make them interact.

06
DAX MeasuresIntermediate
Explain some DAX measures you have created or practised.

“I have practised measures such as Total Sales, Total Profit, Total Quantity and Average Sales. For example, Total Sales = SUM(Orders[Sales]) adds the values in the Sales column. If I need sales for one region, I can use CALCULATE to apply a region filter.”

Total Sales = SUM(Orders[Sales])
Total Profit = SUM(Orders[Profit])
South Sales = CALCULATE([Total Sales], Orders[Region] = "South")

The result of a measure can change when a user changes slicers or other filters in the report.

07
VisualsBeginner
What are some commonly used visuals in Power BI?

“I choose a visual based on the question the report needs to answer. Bar and column charts compare categories; line charts show trends over time; cards highlight one important number; tables show detailed records; matrix visuals summarise data across row and column groups; and scatter charts help explore the relationship between two numeric values. Slicers let users filter the report.”

The goal is to make the information easy to understand, not simply to make the report look attractive.

08
PerformanceIntermediate
What would you do if a Power BI query or report is loading slowly?

“First, I would find out where the delay occurs rather than changing things randomly. I would check whether the source query is slow, Power Query transformations take too long, the data model is too large, or visuals and DAX measures are slow. I would remove unnecessary columns and rows, review expensive transformation steps, check relationships and DAX, and use Performance Analyzer to identify slow visuals. If needed, I would also check source-system performance and whether query folding is possible.”

“The right fix depends on the bottleneck, so I would measure performance before and after each change.”

09
Power QueryIntermediate
What are the different ways to get data into Power BI / Power Query?

“We can get data into Power BI from sources such as Excel, CSV files, SQL Server, other databases, web sources, SharePoint and supported online services. We choose Home → Get data and select the appropriate connector. Choosing Transform data opens Power Query so we can clean or reshape the data before loading it.”

“Import and DirectQuery are different data connectivity modes, not source types. Import loads a copy of data into the model. DirectQuery keeps the data in the source and sends queries to it as users interact with the report. Live connection is also available for supported existing models or Analysis Services sources. The options depend on the connector and source.”

10
Visual SelectionBeginner
What is the difference between a pie chart and a donut chart?

“Both pie and donut charts show how categories contribute to a whole. A pie chart is a full circle, while a donut chart has a hole in the centre that can provide space for a label or total. They are most useful when there are only a few categories and the values form a meaningful whole. If there are many categories or small differences to compare, a bar chart is usually clearer.”

11
Visual SelectionBeginner
What is the difference between a table and a matrix visual?

“A table displays data in rows and columns, which is useful for showing detailed records. A matrix can group data by row and column fields and display subtotals and grand totals, similar to a PivotTable in Excel. I use a table for record-level detail and a matrix when I need grouped summaries or comparisons across categories.”

12
Visual SelectionIntermediate
What is the difference between stacked and clustered bar/column charts?

“A clustered chart places series side by side, making it easier to compare their values. A stacked chart combines series in the same bar or column, showing both the total and each series’ contribution to that total. I use clustered charts when comparing categories is the priority and stacked charts when showing composition is more important. Comparing individual segments in a stacked chart can be harder because they may not share the same baseline.”

13
KPIIntermediate
What is a KPI, and how can you add one to a Power BI report?

“KPI stands for Key Performance Indicator. It is a measurable value used to track progress towards a business goal, such as sales against a target or on-time delivery rate. In Power BI, I can display a KPI using a Card, Gauge or KPI visual, depending on what needs to be communicated. The KPI visual can use an indicator value, a trend axis such as Date, and an optional target. First, I make sure the actual value and target are defined correctly.”

14
Power QueryIntermediate
What are Applied Steps in Power Query?

“Applied Steps is the list of transformations performed in Power Query, such as changing data types, removing columns, filtering rows, merging tables or replacing values. Power Query applies these steps in order whenever the query is evaluated or refreshed. I can select a step to inspect its result, or edit or remove it if needed. The order matters because each step works with the output of the previous step.”

15
Power Query JoinsIntermediate
Which join types are available in Power Query, and what are Left Anti and Right Anti joins?

“Power Query offers six common merge join kinds: Left Outer, Right Outer, Full Outer, Inner, Left Anti and Right Anti. They determine which rows are kept from the two queries.”

  • Left Outer: All rows from the left query and matching rows from the right.
  • Right Outer: All rows from the right query and matching rows from the left.
  • Full Outer: All rows from both queries, matched where possible.
  • Inner: Only rows with matches in both queries.
  • Left Anti: Rows from the left query that have no match in the right.
  • Right Anti: Rows from the right query that have no match in the left.

Before merging, I check that the selected key columns are compatible and that I have selected the correct matching columns.

16
ReportsIntermediate
What is the difference between a report and a dashboard in Power BI?

“A report can contain multiple pages with visuals, slicers and detailed analysis. A dashboard is a single-page canvas in the Power BI Service where users can pin important tiles, often from one or more reports, to monitor key information quickly. Reports are better for exploring data in detail; dashboards are useful for a high-level overview. Dashboards are created in the Power BI Service, not authored in Power BI Desktop in the same way as reports.”

03 / SQL Server

17
Stored ProceduresIntermediate
What is a stored procedure in SQL Server?

“A stored procedure is a named group of SQL statements saved in the database and executed when needed. It can accept parameters, perform database operations and return results. It helps us reuse SQL logic instead of rewriting the same statements. In SQL Server, stored procedures can also be used with transactions and permissions, depending on how they are designed.”

18
ViewsIntermediate
What is a view in SQL Server?

“A view is a named SELECT query that we can query much like a table. It can simplify a complicated query and present only the rows or columns users need, depending on its definition and permissions. A normal view stores the query definition, not a separate copy of its result data. SQL Server also supports indexed views, which have additional requirements and store indexed results.”

19
CTE vs SubqueryIntermediate
Which is better: a CTE or a subquery, and why?

“Neither a CTE nor a subquery is always better. A subquery is a query written inside another SQL statement. A CTE is a named query expression introduced with WITH, which can make complex SQL easier to read and organise. I choose the one that makes the logic clearer. A CTE is not automatically faster; performance depends on the query and SQL Server’s execution plan.”

20
GroupingIntermediate
What is the difference between GROUP BY and PARTITION BY?

“GROUP BY combines rows with the same grouping values and returns a result for each group. PARTITION BY is used with window functions: it divides rows into groups for a calculation but keeps the individual rows in the result.”

For example, GROUP BY Department can return one salary total per department. SUM(Salary) OVER (PARTITION BY Department) can show each employee row alongside the total salary for that employee’s department.

21
FilteringBeginner
What is the difference between WHERE and HAVING?

“WHERE filters individual rows before grouping and aggregation. HAVING filters groups after they have been formed, often using an aggregate condition. For example, WHERE can select orders from 2026, while HAVING can keep only customers whose total sales exceed 10,000.”

SELECT CustomerID, SUM(Sales) AS TotalSales
FROM Orders
WHERE OrderDate >= '2026-01-01'
GROUP BY CustomerID
HAVING SUM(Sales) > 10000;
22
FilteringBeginner
What is the difference between WHERE and GROUP BY?

“WHERE filters which rows are included in a query. GROUP BY groups the remaining rows by one or more columns so we can calculate a result for each group. They do different jobs and are often used together: WHERE filters the rows first, then GROUP BY forms the groups.”

SELECT Region, SUM(Sales) AS TotalSales
FROM Orders
WHERE OrderDate >= '2026-01-01'
GROUP BY Region;

Extra Practice · Power BIBeginner
What is the difference between Power Query and DAX?

“Power Query is mainly used to connect to data and clean or reshape it before loading it into the model. DAX is used to create calculations in the model, such as measures and calculated columns. In short, I use Power Query to prepare the data and DAX to calculate and analyse it.”

25
Extra Practice · Data ModellingIntermediate
What is a relationship in Power BI, and why do we need it?

“A relationship connects tables through related columns, allowing Power BI to use fields from different tables together in a report. For example, a Customers table can connect to an Orders table through CustomerID so that order sales can be analysed by customer. When creating a relationship, I check the key columns, data types, cardinality and filter direction, because an incorrect relationship can lead to incorrect results.”

26
Extra Practice · Report InteractionBeginner
What is a slicer in Power BI?

“A slicer is a visual filter that lets report users choose values such as a year, region or product. It filters the visuals affected by that slicer, making the report interactive without users needing to edit it. The result depends on the model relationships and the visual interaction settings.”

27
Extra Practice · DAXIntermediate
What does CALCULATE do in DAX?

“CALCULATE evaluates an expression after applying or changing filter context. It is useful when I want a measure to calculate under a specific condition.”

Total Sales = SUM(Orders[Sales])
South Sales = CALCULATE([Total Sales], Orders[Region] = "South")

The second measure calculates Total Sales with Region set to South. Other filters, such as Year, can still affect the result unless the expression changes or removes those filters.

28
Extra Practice · DAXIntermediate
What is the difference between SUM and SUMX?

“SUM adds the values in one column. SUMX takes a table, evaluates an expression for each row, and adds the results. I use SUM when the values already exist in a column, and SUMX when I need to calculate a value for each row before adding it.”

SUM(Orders[Sales])
SUMX(Orders, Orders[Quantity] * Orders[UnitPrice])

The SUMX expression calculates Quantity multiplied by UnitPrice for every row and then adds those results.

29
Extra Practice · SQLBeginner
What is the difference between INNER JOIN and LEFT JOIN?

“INNER JOIN returns only rows that have matching values in both tables. LEFT JOIN returns every row from the left table and matching rows from the right; if there is no match, the right-table columns contain NULL. I use LEFT JOIN when I need to keep all records from the left table even when related information is missing.”

30
Extra Practice · SQLBeginner
What is the difference between a primary key and a foreign key?

“A primary key uniquely identifies each row in a table, so its key value cannot be duplicated or NULL. A foreign key references a key in another table and helps ensure that related records are valid. A table has one primary key constraint, which can contain multiple columns, and it can have multiple foreign keys.”

31
Extra Practice · SQLIntermediate
What is the difference between DELETE and TRUNCATE?

“DELETE removes rows and can use a WHERE clause to remove only selected rows. TRUNCATE TABLE removes all rows from a table and does not support WHERE. In SQL Server, TRUNCATE is often efficient for emptying a table, but it has restrictions, including foreign-key-related restrictions. Both can be rolled back when executed inside an appropriate transaction. TRUNCATE also resets an identity counter to its seed, while DELETE does not reset it by itself.”

DELETE FROM Employees WHERE DepartmentID = 5;
TRUNCATE TABLE StagingData;
32
Extra Practice · SQL ServerIntermediate
What is an index, and why do we create one?

“An index is a database structure that helps SQL Server find rows more efficiently, without always scanning the whole table. It can improve queries that filter, join or sort on indexed columns. However, indexes use storage and must be maintained when data changes, so they can slow down INSERT, UPDATE and DELETE operations. I would create indexes based on actual query patterns and performance checks, not on every column by default.”

33
Extra Practice · Data ModellingIntermediate
What is the difference between a measure and a calculated table?

“A calculated table is created with a DAX expression that returns a table. Its rows are stored in the model and it is recalculated during model processing or refresh. A measure returns one value—such as a number, text or date—when a visual or calculation needs it, using the current evaluation context.”

Total Sales = SUM(Orders[Sales])

This is a measure. The following expression returns a table when entered through New Table:

High Sales Orders =
FILTER(Orders, Orders[Sales] > 10000)

“The calculated table is not rebuilt every time a slicer changes. A measure can respond to the current filter context.”

34
Extra Practice · Data ModellingBeginner
What is a semantic model in Power BI?

“A semantic model is the organised data layer that Power BI reports use. It contains the model’s tables, relationships, measures, columns and other model settings. It gives report authors a consistent way to analyse data without having to rebuild the data logic in every report.”
